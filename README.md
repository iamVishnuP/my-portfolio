# 🚀 Vishnu P | Full-Stack Developer Portfolio

Welcome to my personal portfolio repository! This is a modern, premium, high-performance developer portfolio built with React 19, Tailwind CSS, GSAP, and Framer Motion. It showcase my technical capabilities, full-stack systems, education, experience, and projects.

🔗 **Live Demo**: [https://iamvishnup.github.io/my-portfolio](https://movie-project-vishnu.vercel.app/) *(or your deployed custom domain)*

## 🎨 Design & Immersive UX Features

*   **✨ Dynamic Custom Cursor**: A custom GSAP-powered neon cyan dot cursor that morphs fluidly based on what you hover over (clickables, text headings, form fields, and social links).
*   **⏳ Split-Reveal Screen Loader**: A modern, styled page entry loading animation that reveals the portfolio frame smoothly.
*   **📊 Dynamic Stats & Layouts**: Balanced, premium vertical info cards highlighting core engineering benchmarks.
*   **📱 fully Responsive Layout**: Optimized across all devices (Desktop, Tablet, and Mobile screens) with full touch fallbacks.

## 🛠️ Local Development Setup

To run this project locally, clone the repository and install dependencies:

```bash
# Clone the repository
git clone https://github.com/iamVishnuP/my-portfolio.git

# Navigate into the project folder
cd my-portfolio

# Install node packages
npm install

# Start the local development server
npm run dev
```
